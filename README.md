# AI_Displacement_Project

This project contains a global AI workforce displacement dataset and an exploratory analysis script.

## Run the EDA

1. Create and activate the virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Run the analysis script:

```bash
python eda_analysis.py
```

4. Open the generated report and summary:

- `eda_output/eda_report.html`
- `eda_output/summary.md`
